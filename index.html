BoardRunnerFirmware Rehosting and
Cyber-Physical Simulation

Firmware expects a board around it. Rehosting runs that firmware away from its original hardware, so peripheral behavior and the surrounding environment must be represented too.

BoardRunner brings together work on execution, device models, virtual I/O, and physical hardware access to make those interactions available for study.

01 / AN INTERACTION

What has to cross the boundary?

A sensor read, unpacked.

Consider firmware requesting an I²C sensor register. The firmware sees its controller. A controller model can pass the transaction through LibVIO’s I²C bus to a pluggable sensor model, then return the response to the firmware.

↳

Virtual I/O is the interface that lets emulated peripherals exchange data with host resources or other models. LibVIO documents pseudo-terminals, files, networking, signals, DMA, ADC, and SPI/I²C buses; a workflow uses the interfaces it needs.
